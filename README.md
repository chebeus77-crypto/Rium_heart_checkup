# 리움동물의료센터 심장 초음파 검진 소견서 자동 생성 프로그램

본 프로그램은 병원에서 사용하는 기존 `'26년 심장건강검진 소견서.docx'` 원본 양식과 서식(표, 로고, 글꼴, 레이아웃)을 100% 보존하면서, 환자 정보 및 심장초음파 검사 수치를 입력하면 **정상/비정상 자동 판정, 사진 비율 보존 삽입, 병기별 맞춤 보호자 안내문 반영, Word(.docx) 및 PDF 원클릭 생성**을 지원하는 전용 자동화 솔루션입니다.

---

## 🌟 주요 기능 및 특징

1. **환자 정보 간편 입력**: 환자명, 품종, 나이, 성별, 보호자명
2. **신체검사 및 방사선 수치 입력**:
   - 청진: 심잡음 유무 및 등급(Grade) 선택 또는 직접 입력
   - 심박수: 수치 입력 시 자동으로 `xx회/분` 서식 적용
   - X-ray: VHS, VLAS 입력
3. **심장초음파 지표 실시간 자동 판정**:
   - `LA:Ao`: `< 1.6` 정상, `≥ 1.6` **좌심방 확장**
   - `LVIDDn`: `< 1.7` 정상, `≥ 1.7` **좌심실 확장**
   - `E peak`: `< 60` 정상, `≥ 60` **좌심방 압력 증가**
   - `E/E'`: `< 10` 정상, `≥ 10` **좌심실 충만압 증가/폐수종 위험성 증가**
   - *미입력 항목은 임의로 정상 처리하지 않고 `-`로 표시*
4. **ACVIM 병기 선택 및 일관성 있는 반영**:
   - `Stage A / B1 / B2 / C / D` 중 수의사가 직접 선택
   - 2번 진단명, 4번 현재 병기, 7번 보호자 안내문에 환자명과 선택 병기가 일관되게 즉시 자동 반영
   - 보호자 안내문은 기본 문구 제공 외에 수의사가 원하는 대로 즉시 수정 가능
5. **초음파 사진 2장 비율 보존 삽입**:
   - 사진 2장 업로드 시, 기존 양식의 사진 자리에 찌그러짐이나 잘림 없이 완벽한 비율로 자동 교체 삽입
6. **고품질 결과물 출력**:
   - 원클릭 **Word (.docx)** 다운로드
   - MS Word 정식 변환 엔진을 활용한 **무결점 고품질 PDF (.pdf)** 다운로드

## 🚀 실행 방법

### 방법 1: 원클릭 실행 (가장 간단)
폴더 내의 **`실행하기.bat`** 파일을 더블클릭하면 자동으로 웹 브라우저가 열리며 프로그램이 시작됩니다.

### 방법 2: 터미널 명령어로 실행
```bash
cd c:\Users\User\심장검진소견서
uv run streamlit run app.py
```
브라우저 주소: `http://localhost:8501`

## 📁 폴더 구성
- `template.docx`: 병원 원본 Word 소견서 서식
- `report_generator.py`: 소견서 자동 생성 및 판정, PDF 변환 핵심 엔진
- `app.py`: 웹 화면(Streamlit) 인터페이스
- `실행하기.bat`: 더블클릭 실행 배치 파일
- `output/`: 생성된 docx 및 pdf 소견서 저장 폴더
